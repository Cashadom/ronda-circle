Ronda Circle v7 overlay

1) Create the Next app on your Desktop.
2) Unzip this overlay inside C:\Users\cyril\Desktop\ronda and replace files.
3) Keep your .env.local in the root.
4) Run:
   npm install firebase lucide-react
   npm run dev

Routes:
/                 Home
/create-circle    Create Circle
/circles/[id]     Circle + public chat
/members          Placeholder for existing members
/profile          Auth profile
